You are an expert auditor reading a SOC 1 Type II report.
Below is the auditor's opinion section and test results.

Task 1 — Qualified Opinion:
Determine whether the auditor issued a qualified opinion (reservations, exceptions, or adverse
findings in the opinion paragraph itself). If yes, extract the description and any explanation
of why it may or may not be relevant to audit scope.

Practical default:
Most SOC 1 Type II reports have an unqualified opinion and no test exceptions. Do NOT infer a
qualified opinion or exception from generic wording such as "reasonable assurance", "limitations",
"complementary user entity controls", or ordinary test result descriptions. Only set
has_qualified_opinion=true when the opinion paragraph explicitly states qualified/adverse/disclaimer
or equivalent reservation wording. Only add exceptions when the test result explicitly says an
exception, deviation, deficiency, or failure was noted.

Task 2 — Test Exceptions / Deviations:
Extract ALL test exceptions or deviations listed in the report's test results. For each one:
- index: control ID or page reference (e.g. "CC6.1", "Page 45")
- control: name or description of the control tested
- exception_desc: description of the test exception or deviation
- mgmt_response: management's response (empty string if none)
- is_audited: "Audited" if in the audited section, "Unaudited" otherwise
- audit_relevant: "Yes" if relevant to in-scope transaction classes, "No" otherwise

Return ONLY valid JSON — no explanation, no markdown fences:
{{
  "has_qualified_opinion": <true|false>,
  "opinion": {{
    "description": "<opinion text if qualified, else empty string>",
    "explanation": "<relevance to audit scope>"
  }},
  "exceptions": [
    {{
      "index": "<control ID or page ref>",
      "control": "<control description>",
      "exception_desc": "<exception description>",
      "mgmt_response": "<management response or empty string>",
      "is_audited": "Audited",
      "audit_relevant": "Yes"
    }}
  ]
}}

Set "opinion" to null if no qualified opinion. Set "exceptions" to [] if none.
When has_qualified_opinion=false and exceptions=[], the Excel writer will tick the two top
checkboxes on Sheet 3: unqualified opinion and no test exceptions.

{section_text}
